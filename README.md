## 3. Setup

Python 3.9 or newer is recommended.

```bash

cd cv_assignment

python -m venv .venv
# Windows:      .venv\Scripts\activate
```

## 4. How to run

```bash

python src/run_all.py 1 2          # or only some of them
python src/run_all.py --report     # run everything and build the Word report
```

Each task can also be run alone, e.g. `python src/task4_motion.py`.

## 6. Techniques in short

* **Noise + restoration:** Gaussian noise (sigma 25) and salt-and-pepper noise (5 %). Median 3x3 / 5x5 and Gaussian 5x5 filters. PSNR and SSIM from scikit-image.
* **Segmentation:** global / Otsu / adaptive threshold, erosion, dilation, opening, closing (5x5 ellipse), Canny (fixed and median-based thresholds), marker-based watershed with distance transform.
* **Features:** HOG (9 bins, 16x16 cells, 2x2 blocks); SIFT + brute-force matcher + Lowe ratio test (0.75) + RANSAC homography to count inliers; repeated on rotated / resized copies.
* **Detection:** OpenCV Haar cascade (frontal face) and YOLOv8n (COCO) with boxes, labels and scores.
* **Motion:** absolute frame difference; MOG2 Gaussian-mixture background model; Lucas-Kanade tracking of Shi-Tomasi corners with camera-shake compensation.

## 7. Troubleshooting

* *"Could not find your original photograph"* - check the file names in `data/`.
* *Video does not open* - convert a copy with `ffmpeg -i original.MOV -c:v libx264 -crf 18 data/video.mp4`.
* *`cv2.SIFT_create` not found* - upgrade OpenCV: `pip install -U opencv-python`.
* *YOLO cannot download weights* - connect to the internet once, or place `yolov8n.pt` in the project folder.
